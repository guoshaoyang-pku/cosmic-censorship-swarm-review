# Pilot gate checklist

- G1 formulation: model, dimension, topology, data class, asymptotics, genericity, singularity, visibility, and extension regularity are fixed.
- G2 provenance: each literature assertion has a source and exact scope.
- G3 gauge: behavior survives two gauge diagnostics and one curvature invariant.
- G4 numerics: three resolutions, convergence order, constraint residuals, and boundary sensitivity.
- G5 causality: visibility is tested toward the declared infinity; apparent-horizon absence is insufficient.
- G6 stability: perturbation scan classifies open-set, codimension-k, or unresolved.
- G7 independence: separate reviewer reproduces from raw artifacts.

Evidence grades: A rigorous theorem; B independently reproduced converged/computer-assisted result; C internally consistent pilot; D heuristic or unverified output.
