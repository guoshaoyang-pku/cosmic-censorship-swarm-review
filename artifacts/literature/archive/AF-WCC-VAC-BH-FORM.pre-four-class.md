# AF-WCC-VAC-BH-FORM

*Black-hole (trapped-surface) formation results in vacuum, any data class*

Working status: 3 accepted, 0 provisional/unresolved.

## T-201 — Christodoulou 2009: trapped-surface formation from short-pulse vacuum data [accepted]

**Evidence level (derived).** `peer-reviewed`

**Exact statement.** For the Einstein vacuum equations in 3+1 dimensions with no symmetry assumptions, there is an open set of regular initial conditions on an outgoing null hypersurface, of short-pulse type, whose future development forms a trapped surface; the theorems are the first long-time dynamics result for data not confined to a small neighbourhood of Minkowski data.

**Assumptions.** Vacuum Einstein equations; No symmetry assumed; Characteristic initial data on an outgoing null hypersurface plus incoming Minkowski data; Short-pulse (large-amplitude, small-width) incoming gravitational waves

**Conclusion type.** `theorem`

**Sources.** SRC-041, SRC-042

**Scope caveats.** SRC-041 verifies the monograph/conference abstract, not the internal theorem statement; the EMS book DOI is secondary.; Short-pulse data are special, not generic in the space of all AF data.; Trapped-surface formation is not by itself complete future null infinity (WCC), though it is the standard precursor.

**Does not imply.** Does not prove WCC for generic AF vacuum data.; Does not construct a black-hole exterior with complete I+.

**Unresolved.** Precise statement and constants of the main theorem not extracted from the book.; Relation between 'trapped surface forms' and 'I+ is complete' needs the standard global argument, not contained in this theorem.

**Falsifiers.**

- Find an error in the short-pulse mechanism (no retraction found in the verified set).
- Show the trapped surface forms but the solution still has incomplete I+ (would decouple the two notions and change the WCC evidence map).

## T-202 — Klainerman-Rodnianski 2012: simpler trapped-surface formation, enlarged data set [accepted]

**Evidence level (derived).** `peer-reviewed`

**Exact statement.** A simpler proof of finite trapped-surface formation in vacuum, enlarging the admissible set of initial conditions of Christodoulou's short-pulse result and relaxing the propagation estimates, while reducing the number of derivatives of the curvature needed from two to one.

**Assumptions.** Vacuum Einstein equations; Characteristic initial data; finite problem (initial outgoing null hypersurface); No symmetry assumptions

**Conclusion type.** `theorem`

**Sources.** SRC-042

**Scope caveats.** Confirms that T-201's data class is open but special.; Finite problem, not the full past-null-infinity version.

**Does not imply.** Does not prove WCC.

**Unresolved.** Exact definition of the enlarged class not extracted.

**Falsifiers.**

- Locate an error in the relaxed estimates (no retraction found).
- Show the enlarged class fails to contain Christodoulou's, which would contradict the stated comparison.

## T-203 — Li-Yu 2015: complete AF vacuum Cauchy data free of trapped surfaces evolving to a trapped surface [accepted]

**Evidence level (derived).** `peer-reviewed`

**Exact statement.** There exists complete, asymptotically flat vacuum Cauchy initial data, free of trapped surfaces, whose future development must admit a trapped surface; the data equal a constant-time Minkowski slice inside and a constant-time Kerr slice outside.

**Assumptions.** Vacuum Einstein constraint equations; Complete asymptotically flat Cauchy data; Gluing construction using Christodoulou's black-hole formation theorem and Corvino-Schoen gluing

**Conclusion type.** `theorem`

**Sources.** SRC-043

**Scope caveats.** arXiv ID 1207.3164 now directly verified (primary page fetch); the DOI 10.4007/annals.2015.181.2.6 and Annals volume 181(2) 699-768 remain secondary-anchored.; Trapped-surface formation only; no claim about exterior completeness or about I+.

**Does not imply.** Does not prove WCC for generic data.; Does not construct a naked singularity.

**Unresolved.** Verify DOI 10.4007/annals.2015.181.2.6 via Crossref.; Exact differentiability/decay of the glued data not extracted.

**Falsifiers.**

- Find a gap in the gluing argument (no retraction found).
- Show the resulting development fails to be asymptotically flat, which would break the AF class binding.
